# الموقع الشخصي — Ali Nolan

موقع شخصي متكامل مبني بـ **FastAPI** (Python) مع لوحة تحكم عربية لتعديل كل المحتوى، ومعاينة حية أثناء التعديل.

## التشغيل محلياً

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

- الموقع: http://127.0.0.1:8000
- لوحة التحكم: http://127.0.0.1:8000/admin

## لوحة التحكم

- كلمة المرور الافتراضية: `basra2026`
- **غيّرها فوراً** عن طريق متغير البيئة `ADMIN_PASSWORD` (في Render: Settings → Environment).
- كل التعديلات تنحفظ بملف `content.json`، وتظهر مباشرة بالمعاينة قبل الحفظ.

## متغيرات البيئة

| المتغير | الوصف | الافتراضي |
| --- | --- | --- |
| `ADMIN_PASSWORD` | كلمة مرور لوحة التحكم | `basra2026` |
| `SECRET_KEY` | مفتاح تشفير الجلسات | غيّره بالإنتاج |

## البنية

```
main.py              # تطبيق FastAPI
content.json         # محتوى الموقع (يتعدل من لوحة التحكم)
requirements.txt
render.yaml          # إعدادات النشر على Render
templates/
  index.html         # صفحة الموقع
  admin.html         # لوحة التحكم (عربي RTL + معاينة حية)
  login.html         # تسجيل دخول اللوحة
static/
  style.css          # تصميم الموقع
  main.js            # عرض المحتوى + الأنميشن + المعاينة الحية
```

## ملاحظة عن الاستضافة المجانية

على الخطة المجانية من Render نظام الملفات مؤقت: التعديلات من لوحة التحكم ترجع للافتراضي بعد إعادة النشر (redeploy). للتعديل الدائم عدّل `content.json` بالمستودع، أو شغّل الموقع على سيرفر بقرص دائم.
